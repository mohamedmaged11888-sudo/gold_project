# 🏆 Gold Price Prediction using Machine Learning

## 📌 Project Overview

This project predicts gold prices using Machine Learning techniques in Python. The project includes data cleaning, exploratory data analysis, feature engineering, model training, and prediction.

The objective is to build an accurate predictive model that estimates gold prices based on historical market data.

---

## 📊 Dataset

The dataset contains historical gold price information including market-related features used for prediction.

Example files:

- gold_prices.csv
- gold_prices_cleaned.csv
- filtered_gold.csv

---

## 🚀 Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Selection
- Machine Learning Model Training
- Gold Price Prediction
- Performance Evaluation
